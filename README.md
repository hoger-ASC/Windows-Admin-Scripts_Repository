 The purpose of these scripts is to create automation templates for common Windows IT Admin tasks, with the following means and traits:
 - .csv format for machine readable information exchange
 - SSL encryption based on ticketing platform for communications
 - Active Directory and network configuration

    In the case an admin uses these scripts, the workflow is:
### Ticketing platform handles authentication & encryption -> stakeholder submits ticket alongside filled out CSV template -> administrator reviews ticket and executes script
